# OrcaSlicer-AI: установка и плагины (Windows)

OrcaSlicer-AI — это OrcaSlicer 2.5 с дополнительным plugin API v1. Через этот API плагины читают текущие
пресеты и предлагают изменения, которые вы подтверждаете в окне OrcaSlicer. Возможности поставляются
отдельными плагинами:

| Плагин | Файл | Что делает |
|---|---|---|
| AI Assist | `orca_ai_assist.py` | Анализ пресетов и описание дефектов печати через Gemini, применение выбранных рекомендаций |
| Filament QR | `orca_filament_qr.py` | QR-этикетки для катушек, выбор филамента сканированием с телефона |

## 1. Установка OrcaSlicer-AI

1. Откройте страницу [Releases](https://github.com/Jkl88/OrcaSlicer-AI/releases/latest).
2. Скачайте `OrcaSlicer_Windows_*.exe` (установщик) и запустите его.
   Если Windows SmartScreen предупредит о неизвестном издателе: «Подробнее» → «Выполнить в любом случае».
3. Ваши профили и настройки OrcaSlicer сохраняются: используется тот же каталог данных
   (`%APPDATA%\OrcaSlicer`).

## 2. Установка плагинов

1. Скачайте из того же релиза нужные `.py`-файлы.
2. В OrcaSlicer: **Файл → Plugins** (или пункт **Plugins** в главном меню).
3. Нажмите **Install local plugin** и выберите файл. При первой установке OrcaSlicer скачает зависимости
   плагина — нужен интернет.
4. У каждого плагина появится своя вкладка в верхней панели рядом с «Подготовка» и «Предпросмотр».
   Если вкладки нет, включите плагин в окне Plugins.

Обновление: установите новый файл плагина тем же способом — OrcaSlicer предложит заменить старую версию.
Данные плагина (настройки, база катушек) при этом сохраняются.

## 3. Как подтверждаются изменения

Плагины ничего не меняют молча. Когда плагин хочет поменять настройку или профиль в слоте филамента,
OrcaSlicer показывает окно со списком: пресет, параметр, текущее и новое значение. Кнопка «Применить»
применяет всё сразу, «Отмена» — ничего не меняет.

Изменённые пресеты помечаются как изменённые, но не сохраняются автоматически: сохраните их как обычно,
если результат вас устраивает.

## 4. Плагины по отдельности

- [AI Assist](../plugins/ai_assist/README.md) — ключ Gemini, какие данные уходят в Gemini, как применять рекомендации.
- [Filament QR](../plugins/filament_qr/README.md) — этикетки, подключение телефона, безопасность.

## 5. Что изменилось по сравнению с OrcaSlicer-AI 2.5.0-ai.2

- Встроенное окно «Справка → AI Assist» и вкладка настроек AI Assist удалены — их заменяет плагин AI Assist.
  Ключ Gemini нужно один раз ввести в плагине: старый ключ из настроек OrcaSlicer не переносится.
- Мониторинг камеры, Telegram-уведомления и остановка печати через Moonraker в этот выпуск не входят.

## 6. Если что-то не работает

- **Вкладка плагина не появилась** — проверьте в окне Plugins, что плагин включён и нет ошибки установки
  (ошибки зависимостей обычно связаны с отсутствием интернета при установке).
- **Телефон не открывает страницу Filament QR** — включите доступ из сети в плагине, разрешите OrcaSlicer
  в брандмауэре Windows для частной сети, проверьте, что телефон в той же Wi-Fi-сети.
- **«Состояние OrcaSlicer изменилось»** — пока плагин готовил изменение, вы поменяли пресеты.
  Повторите действие: плагин возьмёт свежее состояние.
- Журнал OrcaSlicer: **Справка → Открыть папку слайсера** → папка `log`.
