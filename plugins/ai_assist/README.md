# AI Assist — плагин OrcaSlicer

Плагин анализирует текущие пресеты процесса, пластика и принтера с помощью ИИ и предлагает правки.
Подходит любой из сервисов: Google Gemini, любой OpenAI-совместимый API (OpenAI, OpenRouter, DeepSeek, Groq,
Mistral, а также локальные Ollama и LM Studio) или Anthropic Claude. Можно описать дефект печати текстом («слоновья нога», «задираются углы», «паутина») и получить
рекомендации под него. Каждая рекомендация показывается отдельной строкой: категория, параметр,
текущее значение, предлагаемое значение и причина. Применяются только строки, которые вы отметили.

Плагин версионируется отдельно от OrcaSlicer. Текущая версия — 1.2.0. Для применения правок нужен
официальный OrcaSlicer 2.5.0 или новее. В более старых версиях работает ручной режим (см. ниже).

## Установка

1. Скачайте один файл `orca_ai_assist.py`.
2. В OrcaSlicer откройте окно **Плагины** (Plugins), нажмите **Установить локальный плагин** (Install local plugin) и выберите этот файл.
   Внешние зависимости не нужны, используется только стандартная библиотека Python.
3. Подтвердите разрешения, которые запросит OrcaSlicer: доступ в сеть к
   `https://generativelanguage.googleapis.com`, `https://api.openai.com`, `https://api.anthropic.com` и запуск
   фоновых потоков. Если вы укажете другой адрес API (OpenRouter, DeepSeek, свой сервер), OrcaSlicer спросит
   разрешение на него при первом запросе: подтвердите доступ и повторите запрос. Выданные разрешения видны
   и меняются в окне «Плагины».
4. Откройте страницу **AI Assist**.

Обновление — установка новой версии файла с перезаписью старой. Настройки при этом сохраняются.

## Настройка ИИ-сервиса

1. В блоке «ИИ-сервис» выберите сервис:
   - **Google Gemini** — ключ из [Google AI Studio](https://aistudio.google.com/apikey);
   - **OpenAI-совместимый** — ключ вашего сервиса и его адрес API, например `https://api.openai.com/v1`,
     `https://openrouter.ai/api/v1`, `https://api.deepseek.com/v1`. Для Ollama (`http://localhost:11434/v1`)
     и LM Studio (`http://localhost:1234/v1`) на этом компьютере ключ не нужен;
   - **Anthropic Claude** — ключ из Anthropic Console.
2. Вставьте ключ, при необходимости поменяйте адрес API и нажмите «Сохранить». Сохраняются все поля,
   ключ при этом не проверяется. Если какое-то поле введено неверно, сохраняются остальные, а
   страница говорит, что исправить.
3. После сохранения плагин загружает список моделей, доступных с этим ключом. Выберите модель в выпадающем
   списке: выбор сохраняется сразу. Кнопка «Загрузить модели» обновляет список. Модель можно ввести
   и вручную, например `openai/gpt-4o` или `llama3.1:8b`.

Для каждого сервиса хранятся свои ключ, адрес, модель и согласие, так что между сервисами можно
переключаться без повторного ввода. Настройки версии 1.0–1.1 (только Gemini) переносятся автоматически.

Ключи хранятся в файле `config.json` в личной папке плагина, которую выдаёт OrcaSlicer
(`orca.host.plugin.storage()`). Запись атомарная, на Linux и macOS файл доступен только владельцу (`0600`).
Страница видит только признак «ключ задан / не задан». В адрес запроса ключ не попадает: он передаётся
в заголовке (`x-goog-api-key`, `Authorization` или `x-api-key`). Из сообщений об ошибках ключи вырезаются.

Если OrcaSlicer не предоставляет хранилище плагина, плагин сообщит, что настройки нельзя сохранить.
Ключ и согласие тогда действуют только до перезапуска программы. В домашнюю или текущую папку
плагин ничего не пишет.

## Что отправляется в ИИ-сервис

Перед первым запросом к каждому сервису нужно явно отметить согласие на странице. Согласие можно
отозвать, тогда запросы к этому сервису прекратятся.

Отправляется:

- имена текущих пресетов процесса, пластика и принтера;
- текущие значения параметров из фиксированного списка (`SNAPSHOT_KEYS` в коде; полный список
  показан на странице в разделе «Разрешённые параметры»): высота слоя, периметры, заполнение,
  скорости, компенсация «слоновьей ноги», кайма, поддержки, температуры, охлаждение, поток, откат,
  ограничения кинематики и т. п.;
- текст описания дефекта, если вы его ввели.

Не отправляется: ключи API, токены, пароли, адрес и логин хоста печати (`print_host`,
`printhost_apikey` и т. п.), пути к файлам, G-code, модели и метаданные проекта.

## Режимы работы

Плагин сам определяет возможности OrcaSlicer по наличию функций API. Номер версии программы для
этого не используется.

**Автоматический режим.** Включается, если OrcaSlicer предоставляет API изменения пресетов
`orca.host.preset` (OrcaSlicer 2.5.0 и новее). Отмеченные строки применяются по категориям: для
каждой категории с отмеченными строками есть своя кнопка «Применить: Процесс», «Применить: Пластик»
или «Применить: Принтер». Перед применением OrcaSlicer показывает окно подтверждения со списком
изменений «параметр: было → станет». Изменения одной категории применяются целиком или не
применяются вовсе. Изменения разных категорий применяются раздельно. Пресеты при этом не
сохраняются, а становятся «изменёнными»: сохраните их сами, если результат устраивает.

Перед применением плагин сверяет текущие значения с теми, на которых строился анализ. Если вы
поменяли значение или переключили пресет после анализа, применение отклоняется и анализ нужно
запустить заново. Правка пластика применяется к пресету с вкладки «Пластик». Этот пресет должен
быть выбран хотя бы в одном слоте филамента. Если OrcaSlicer спросит про несохранённые изменения
и вы откажетесь, ничего не применится.

**Ручной режим.** Работает в версиях OrcaSlicer до 2.5.0, где плагины могут только читать пресеты.
Анализ доступен, а кнопка называется «Скопировать инструкции». Она выдаёт текст вида
`Категория / параметр / текущее / предлагаемое`, и значения переносятся в пресеты вручную.

Если OrcaSlicer не даёт плагинам читать пресеты, анализ недоступен. Страница сообщает об этом.

## Ограничения

- Анализируются и меняются только пресеты, которые сейчас открыты на вкладках процесса, пластика и
  принтера. При нескольких филаментах — только тот, что на вкладке «Пластик».
- Модель может ошибаться, поэтому проверяйте каждую строку перед применением. Ответы с неизвестными
  полями, параметрами вне списка, секретными ключами или повторами отклоняются целиком. Окончательная
  проверка значений остаётся за OrcaSlicer.
- Запрос ограничен по времени (около 60 секунд) и по размеру ответа (2 МиБ). Его можно отменить.
- Нужен доступ к выбранному ИИ-сервису (для облачных сервисов — интернет). Запросы тратят квоту вашего ключа.
- В этой версии нет мониторинга печати: веб-камеры, уведомлений в мессенджеры и управления
  принтером.

## Тесты

Тестам не нужны ни OrcaSlicer, ни сеть: ИИ-сервисы заменяются локальным HTTP-сервером, а модуль `orca` —
заглушкой.

```bash
python3 -m unittest discover -s plugins/ai_assist/tests -t plugins/ai_assist -v
```
