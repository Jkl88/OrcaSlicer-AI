# Filament QR Manager — OrcaSlicer

**Версия:** 0.1.0 (прототип). Русский интерфейс. Бесплатно, автономно, без облака.

Прототип для учёта катушек и QR-этикеток. Каждая катушка имеет **уникальный код** `FQ-XXXXXX` и привязку к **сохранённому** профилю конкретного принтера в OrcaSlicer. Несколько катушек PLA/PETG могут использовать один профиль либо разные профили с разными настройками.

## Что уже реализовано

- Реальный Python-плагин с вкладкой **Filament QR** для OrcaSlicer, поддерживающего Python Plugin System (nightly / версии новее 2.4.2).
- Просмотр доступных сохранённых профилей филамента и текущего принтера через официальный `orca.host` API.
- Регистрация катушек, привязка к **имени профиля** и **имени принтера**, хранение в SQLite внутри приватного хранилища плагина.
- Постоянные короткие уникальные коды без зависимости от IP-адреса компьютера. Сами QR содержат `FQ:FQ-XXXXXX`.
- QR-наклейка в SVG **56 × 72 мм**, тип материала и короткий код в самом центре; печать из браузера; пример PNG/SVG приложен.
- Локальный HTTP-сервер на **0.0.0.0:8765**, мобильная страница, пароль-подключение по PIN из интерфейса Orca, ручной код, получение фото QR с камеры (`input capture=environment`), серверная расшифровка ZXing.
- Проверка привязки к принтеру, обнаружение признака несохранённого профиля, очередь сканирования и синхронизация с вкладкой Orca.
- Без записи или замены файлов профилей OrcaSlicer. Катушки сохраняются независимо.

## Главное ограничение — автоматическое переключение

**В штатной версии OrcaSlicer автоматическое переключение пока НЕ реализовано.** По состоянию на ноябрь 2026 официальный Python API `orca.host` допускает чтение пресетов, но не содержит функции переключения/сохранения активного пресета. Мы не обходим этот запрет записью в `config.ini` или имитацией кликов, потому что это может уничтожить несохранённые пользовательские настройки.

Фактический поток в версии 0.1.0: отсканировали QR → сервер нашёл профиль → запись появилась в **Filament QR** в OrcaSlicer → при наличии несохранённых изменений показывается предупреждение → пользователь сохраняет текущий профиль и **выбирает указанный профиль обычным селектором OrcaSlicer** → плагин замечает, что он активен, и сбрасывает заявку.

**Что нужно для полного автопереключения:** небольшой upstream/локальный C++ bridge в `src/slic3r/plugin/host/` с функцией `select_filament_preset(name, slot)`; вызов должен происходить в GUI-потоке через существующий код выбора/обработки `Tab::select_preset()` и встроенный `UnsavedChangesDialog` (см. `src/slic3r/GUI/Tab.cpp`). При отказе пользователя сохранять/переключать изменения ничего не меняется. После подтверждения нужен контроль активного профиля. Для многосопловой печати `slot` должен задаваться явно. Это требует совместимой сборки Orca, так как C++ метод пока отсутствует в официальном API. Наличие метода в плагине сейчас *не предполагается*.

## Установка в OrcaSlicer

1. Установите сборку OrcaSlicer с меню **Plugins** и поддержкой Python-плагинов (nightly либо версия новее **2.4.2**).
2. Распакуйте архив. В OrcaSlicer откройте **Plugins → Browse plugins → Install local plugin** и укажите `orca_filament_qr.py`.
3. При установке плагин должен разрешить зависимости `qrcode`, `Pillow`, `zxing-cpp` через встроенный менеджер `uv`; потребуется интернет один раз. Разрешите сетевой сокет `0.0.0.0:8765` и создание фонового потока при запросе разрешений.
4. Включите capability **Filament QR**. Появится одноимённая вкладка. Если сервер не стартовал, смотрите статус в ней.
5. В Windows разрешите частный входящий TCP-порт **8765** в брандмауэре (только профиль частной/домашней сети). Не открывайте порт в интернет.
6. Сохраните созданный/откалиброванный профиль в настройках пластика OrcaSlicer **обычной кнопкой Save**. Вкладка **Filament QR** → выберите профиль → тип (PLA/PETG/ABS и т.д.) → производителя/цвет → **Создать катушку и QR**.
7. Для печати откройте на самом ПК `http://127.0.0.1:8765/label/FQ-XXXXXX`, заменив код на выданный. Наклейку можно печатать и из карточки катушки с телефона после PIN.
8. На телефоне (та же Wi-Fi-сеть) откройте `http://IP-КОМПЬЮТЕРА:8765`, введите PIN из вкладки, нажмите **Открыть камеру** и снимите QR-наклейку либо введите код вручную.
9. Состояние сканирования видно во вкладке. Сохраняйте изменённый профиль перед ручным переключением на указанный профиль.

> Камера мобильного браузера **в режиме живого видеопотока** через HTTP LAN обычно не работает без доверенного HTTPS. Здесь используется системный захват фотографии через `<input type="file" capture="environment">`, которому HTTPS для доступа к файловому/камерному пикеру не требуется. Распознавание выполняется на компьютере. Если на телефоне системный браузер не предложит камеру, можно выбрать готовую фотографию QR.

> QR содержит только ID катушки, не URL, чтобы наклейки продолжали работать при смене IP ПК. База находится в папке приватных данных плагина. Делайте резервную копию `filament_qr.sqlite3` перед переустановкой плагина. В локальной сети используется HTTP, поэтому используйте только доверенную сеть и не подключайтесь через публичные Wi-Fi.

## Запуск для проверки без OrcaSlicer

Требуется Python 3.12+ и зависимости:

```powershell
py -3.12 -m pip install -r requirements.txt
py -3.12 .\orca_filament_qr.py --standalone
```

Страница: `http://127.0.0.1:8765`. PIN выводится в консоли. Тестовые профили: `Generic PLA @ Demo` / `PETG @ Demo`. Этот режим не связан с настоящим OrcaSlicer.

Тесты (один использует только необязательные библиотеки для проверки читаемости QR):

```powershell
py -3.12 -m unittest discover -s tests -v
```

## Безопасность и дальнейшая работа

- Все изменяющие действия происходят через POST с PIN-сессией, cookie `HttpOnly; SameSite=Strict`; число ошибочных PIN ограничено. Но HTTP не шифрует трафик.
- Сервер принимает входящие запросы внутри локальной сети. Не делайте проброс TCP-порта наружу.
- При одновременной работе нескольких OrcaSlicer один порт сможет занять только один экземпляр.
- Внешние файлы Orca и их сохранение не затрагиваются. «Save current preset» и «Select filament» — дальнейшая нативная интеграция, не готовая часть этого релиза.
- До полноценного релиза нужно: протестировать установку/встраивание на реальной версии OrcaSlicer; проверить Windows Defender Firewall и совместимость Python-зависимостей; добавить native bridge, выбор слот/экструдер, печать пакетных наклеек и backup/restore.
